Algoritmo de procesamiento de los datos de los sensores

Para procesar los datos de los sensores en tiempo real usamos la función `processRawLine`. El flujo de datos funciona así:

Primero, tomamos la línea de texto que manda el Web Worker. Usamos una expresión regular (/[A-Z]\d+/i) para identificar el código del sensor. Como ejemplo puede ser: Y1001 o L1002

Luego, aislamos la parte que está entre los corchetes, la dividimos usando comas y convertimos los textos a números flotantes con "parseFloat". Seguidamente, filtramos cualquier valor nulo o inválido y nos quedamos con el arreglo limpio de microsensores

Por último, sumamos esos valores para sacar el promedio simple (la medida Macondiana). Retornamos la cadena formateada a 3 decimales para la pantalla de "serie" y mandamos el número al estado del "Chart" para que la gráfica en tiempo real se vaya dibujando
