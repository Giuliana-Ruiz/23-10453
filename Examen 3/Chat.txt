[Giuliana Ruiz]: 
Ok ahora conecté el Web Worker (`tgmr-thx-1138.js`). El evento `onmessage` me está tirando strings tipo `"Y1001 [ 12.3, 14.5, 11.2 ]"`. Hice una función `processRawLine` con `.split()`, pero si viene un espacio raro o un dato corrupto, `parseFloat` me devuelve `NaN` y rompe la aplicación. ¿Cómo puedo limpiar la línea con Regex antes de convertir los números?

[IA]: 
Te conviene usar dos expresiones regulares: una para el ID del sensor y otra para capturar lo que hay dentro de los corchetes:

export function processRawLine(raw: string) {
  const idMatch = raw.match(/[A-Z]\d+/i);
  const bracketMatch = raw.match(/\[(.*?)\]/);

  if (!idMatch || !bracketMatch) return null;

  const id = idMatch[0];
  const rawValues = bracketMatch[1].split(',');

  const values = rawValues
    .map(v => parseFloat(v.trim()))
    .filter(n => !isNaN(n));

  if (values.length === 0) return null;

  const sum = values.reduce((acc, curr) => acc + curr, 0);
  const average = sum / values.length;

  return {
    id,
    values,
    average: parseFloat(average.toFixed(3))
  };
}

    const parsed = processRawLine(e.data);

    }
  };

  worker.addEventListener('message', handleMessage);
  return () => worker.removeEventListener('message', handleMessage);
